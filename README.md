# ZivugArch — Simplified Architecture Prototype

This is the calmer UI pass based on the existing `shidarch` architecture and the approved Warm Modern Dashboard direction.

## Goal

Keep the same core concepts — Recent, Guys, Girls, Shadchanim, Shidduchim, sources, ideas, waiting-on-them / waiting-on-me, Single / Shadchan modes — while exposing far fewer controls at once.

The main screens intentionally hide secondary sorting, grouping, dormant filters, display preferences, and other advanced controls behind one settings/filter sheet.

All people and activity in this prototype are fictional. No messages are sent and no production data is stored.

## Prototype focus

- Five stable bottom tabs
- Warm / Dark theme
- Comfortable / Compact density
- Optional summary cards
- 112 synthetic shadchan records to test list scale
- Source batch example (`Rivka's 10 shadchanim`)
- Idea before shidduch
- Person / shadchan / source / shidduch detail screens
- `History` as the broad activity timeline label
